<h1>Flexwalk</h1>
This project focuses on designing and fabricating a humanoid bipedal lower body (40-50 cm height) inspired by open-source humanoid platforms such as Asimov.
<br>We will develop a mechanically feasible lower-body humanoid structure capable of replicating human leg kinematics using Hip (Roll + Pitch), Knee (Pitch), and Ankle (Pitch) joints.

<h1>Dependencies</h1>
<ul>
  <li>Mechanical Design</li>
  <li>3D Printing</li>
  <li>Kinematics</li>
</ul>
